Programmieren mit KI

Vom Autovervollständigen bis zur App aus einem Satz. Diese Werkzeuge schreiben Code, prüfen Code und erklären dir Code, den du vor drei Jahren selbst geschrieben und erfolgreich verdrängt hast.

Programmieren mit KI teilt sich grob in zwei Lager. Das eine hilft Entwicklern im Editor: Cursor, GitHub Copilot, Claude Code oder Windsurf schlagen Code vor, bauen ganze Funktionen und erklären Fehlermeldungen. Das andere baut aus einer Beschreibung gleich eine ganze App, etwa Lovable, Bolt.new oder v0.

Beides spart Zeit, beides braucht jemanden, der hinterher draufschaut. KI-Code sieht oft richtig aus, bevor er richtig ist. Deshalb liegen hier auch Werkzeuge für Code-Reviews und Tests. Lovable kommt übrigens aus Stockholm, falls du einen EU-Builder suchst.

Werkstatt-Tipp

Lass die KI zuerst die Tests schreiben und dann den Code. Wenn die Tests grün werden, weißt du wenigstens, was „funktioniert“ heißen sollte.

Fragen aus der Werkstatt

Programmieren mit KI: kurz beantwortet

Welcher KI-Code-Assistent ist der beste?

Den einen für alle gibt es nicht. Cursor und Windsurf sind eigene Editoren, GitHub Copilot steckt in vielen bestehenden Editoren, Claude Code arbeitet im Terminal. Probier zwei davon an deinem echten Projekt aus, nicht an einer Demo.

Kann ich ohne Programmierkenntnisse eine App bauen?

Für Prototypen ja: Lovable, Bolt.new oder v0 machen aus einer Beschreibung eine lauffähige App. Sobald echte Kundendaten oder Zahlungen im Spiel sind, sollte jemand drüberschauen, der den Code versteht.

Darf KI-generierter Code in mein Projekt?

Technisch ja. Rechtlich lohnt ein Blick in die Bedingungen des Anbieters und in die Regeln deines Arbeitgebers. Das Review bleibt Pflicht, ganz egal, wer oder was den Code geschrieben hat.
