43 KI-Begriffe.

Die Wörter, die dir in Tool-Beschreibungen, Preislisten und Datenschutz-Runden um die Ohren fliegen. Jeder Begriff mit einer ernsten Erklärung und einer Werkstatt-Übersetzung, damit er auch hängen bleibt.

A

Agent

#

Ein Sprachmodell, das nicht nur antwortet, sondern Werkzeuge benutzt und mehrere Schritte selbst plant: suchen, klicken, Dateien schreiben, Mails verschicken. Je mehr ein Agent darf, desto wichtiger sind Freigaben und Protokolle.

Werkstatt-Übersetzung: Ein Praktikant mit Schlüsselbund. Gib ihm nur die Schlüssel, die er wirklich braucht.

Siehe auch: Tool Use MCP Guardrails

Agent Skills

#

Offener Standard, mit dem Agenten Fachwissen nachladen: ein Ordner mit einer Datei SKILL.md, die eine Aufgabe beschreibt, plus Skripte und Vorlagen. Seit Oktober 2026 betreut ihn die Agentic AI Foundation der Linux Foundation.

Werkstatt-Übersetzung: Die Arbeitsmappe, die der Agent aufschlägt, bevor er loslegt.

Siehe auch: Agent MCP System-Prompt

API

#

Schnittstelle, über die Programme miteinander reden. Wer ein Sprachmodell in Shop, CMS oder Skript einbauen will, nutzt die API des Anbieters und zahlt meist pro Token.

Werkstatt-Übersetzung: Die Durchreiche zwischen zwei Programmen: Bestellung rein, Ergebnis raus.

Siehe auch: Token Rate Limit

AVV

#

Auftragsverarbeitungsvertrag nach Art. 28 DSGVO. Den brauchst du, wenn ein Dienstleister personenbezogene Daten in deinem Auftrag verarbeitet. Bei KI-Tools mit Kundendaten: vorher abschließen, nicht hinterher.

Werkstatt-Übersetzung: Der Zettel, den du unterschreibst, bevor jemand anders deine Kundenkartei anfasst.

Siehe auch: DSGVO EU AI Act

Langdock

B

Benchmark

#

Standardisierter Test, mit dem Modelle verglichen werden. Ein guter Benchmark-Wert heißt nicht, dass ein Modell deine Aufgabe gut löst. Teste mit zehn echten Beispielen aus deinem Alltag.

Werkstatt-Übersetzung: Das Ergebnis vom Prüfstand. Sagt viel über den Prüfstand und etwas über die Straße.

Siehe auch: Halluzination LLM

C

C2PA und Wasserzeichen

#

Kennzeichnung KI-erzeugter Inhalte. C2PA hängt signierte Herkunftsdaten an Bilder und Videos. Sichtbare Wasserzeichen lassen sich leicht entfernen, Metadaten auch.

Werkstatt-Übersetzung: Der Herkunftsstempel auf dem Bild. Hält, solange keiner ihn abschleift.

Siehe auch: Deepfake Diffusionsmodell

Schublade: Bilder

Chatbot

#

Programm, mit dem du per Text oder Sprache redest. Heute meist ein Sprachmodell mit Oberfläche, etwa ChatGPT, Claude oder Le Chat.

Werkstatt-Übersetzung: Der Kollege am Tresen, der immer Zeit hat und nie Kaffeepause macht.

Siehe auch: LLM System-Prompt

ChatGPTClaudeLe Chat von MistralSchublade: Text und Sprache

Computer Use

#

Ein Modell bedient Bildschirm, Maus und Tastatur oder einen Browser selbst, statt nur Text zu liefern. Praktisch für Formulare und Altsysteme ohne Schnittstelle, riskant ohne klare Grenzen.

Werkstatt-Übersetzung: Der Praktikant darf jetzt an die Maus. Bleib in der Nähe.

Siehe auch: Agent Tool Use Prompt Injection

ClaudeSchublade: Automatisierung und KI-Agenten

D

Deepfake

#

Täuschend echte, KI-erzeugte Bilder, Videos oder Stimmen einer realen Person. Der EU AI Act verlangt, solche Inhalte als künstlich erzeugt offenzulegen.

Werkstatt-Übersetzung: Bei „täuschend echt“ ist das Täuschen das Problem, nicht das Echte.

Siehe auch: C2PA und Wasserzeichen EU AI Act Text-to-Speech

Schublade: Video

Diffusionsmodell

#

Bildmodell, das aus Rauschen Schritt für Schritt ein Bild formt, gesteuert durch deinen Prompt. Stable Diffusion und FLUX arbeiten so.

Werkstatt-Übersetzung: Ein Bildhauer, der aus Rauschen meißelt statt aus Marmor.

Siehe auch: LoRA Prompt

Stable DiffusionFLUX von Black Forest LabsSchublade: Bilder

DSGVO

#

Die Datenschutz-Grundverordnung der EU. Für KI-Tools zählt: Welche Daten gibst du ein, wo werden sie verarbeitet, gibt es einen AVV, und wird mit deinen Eingaben trainiert?

Werkstatt-Übersetzung: Die Hausordnung für personenbezogene Daten. Gilt auch für Roboter.

Siehe auch: AVV Lokales Modell EU AI Act

E

Embedding

#

Ein Text als Zahlenreihe, die seine Bedeutung abbildet. Ähnliche Texte bekommen ähnliche Zahlen. Damit funktionieren semantische Suche und RAG.

Werkstatt-Übersetzung: Der Geruch eines Textes in Zahlen: Ähnliches riecht ähnlich.

Siehe auch: RAG Vektordatenbank

Schublade: Entwickler-Tools und LLMOps

EU AI Act

#

EU-Verordnung über künstliche Intelligenz, in Kraft seit 1. August 2024 und stufenweise anwendbar. Sie teilt KI-Systeme nach Risiko ein. Seit Februar 2025 müssen Unternehmen, die KI einsetzen, für ausreichende KI-Kompetenz ihrer Leute sorgen.

Werkstatt-Übersetzung: Die Straßenverkehrsordnung für KI, inklusive Fahrstunden für alle, die sie im Betrieb einsetzen.

Siehe auch: DSGVO Deepfake

F

Few-Shot

#

Prompt-Technik: Du gibst dem Modell zwei bis fünf Beispiele, wie die Antwort aussehen soll. Oft der schnellste Weg zu gleichbleibendem Format.

Werkstatt-Übersetzung: Zeigen statt erklären. Drei Beispiele sagen mehr als drei Absätze Anleitung.

Siehe auch: Prompt Zero-Shot

Fine-Tuning

#

Ein fertiges Modell mit eigenen Beispielen nachtrainieren, damit es Stil, Format oder Fachsprache übernimmt. Für Wissen ist RAG meist billiger und aktueller.

Werkstatt-Übersetzung: Eine Umschulung für ein Modell, das eigentlich schon einen Job hat.

Siehe auch: LoRA RAG

Hugging FaceSchublade: Entwickler-Tools und LLMOps

G

GPU

#

Grafikprozessor. Rechnet die vielen parallelen Multiplikationen, aus denen KI-Modelle bestehen. Für lokale Modelle zählt vor allem der Grafikspeicher (VRAM).

Werkstatt-Übersetzung: Der Motorblock. Bei lokalen Modellen zählt der Hubraum, und der heißt hier VRAM.

Siehe auch: Lokales Modell Quantisierung Inferenz

Guardrails

#

Regeln und Filter um ein Modell herum: was es darf, was es nicht ausgeben soll, wann ein Mensch freigibt. Pflicht, sobald ein Agent handeln darf.

Werkstatt-Übersetzung: Leitplanken. Fallen erst auf, wenn man sie dringend braucht.

Siehe auch: Agent Prompt Injection

H

Halluzination

#

Das Modell erfindet etwas und klingt dabei sicher: Quellen, Zahlen, Paragrafen. Gegenmittel: Quellen verlangen, mit RAG arbeiten, Fakten selbst prüfen.

Werkstatt-Übersetzung: Der Kollege, der lieber etwas erfindet, als „weiß ich nicht“ zu sagen.

Siehe auch: RAG KI-Suchmaschine

I

Inferenz

#

Der Moment, in dem ein trainiertes Modell eine Antwort berechnet. Inferenz kostet Rechenzeit, deshalb rechnen Anbieter pro Token ab.

Werkstatt-Übersetzung: Der Moment, in dem der Motor läuft und der Taxameter tickt.

Siehe auch: Token GPU

K

KI-Suchmaschine

#

Suche, die Treffer liest und dir eine zusammengefasste Antwort mit Quellen gibt. Spart Klicks, ersetzt aber nicht das Lesen der Quelle.

Werkstatt-Übersetzung: Der Bibliothekar, der dir die Antwort vorliest und die Bücher gleich danebenlegt.

Siehe auch: Halluzination RAG

PerplexitySchublade: Text und Sprache

Kontextfenster

#

Wie viel Text ein Modell auf einmal berücksichtigt: Prompt, angehängte Dateien und bisheriger Chat, gemessen in Token. Was nicht reinpasst, ist für das Modell nicht da.

Werkstatt-Übersetzung: Die Größe der Werkbank. Was nicht draufpasst, fällt hinten runter.

Siehe auch: Token RAG

L

LLM

#

Large Language Model, auf Deutsch großes Sprachmodell. Trainiert auf riesigen Textmengen, sagt es das wahrscheinlich nächste Wortstück voraus. Darauf bauen ChatGPT, Claude, Gemini und Le Chat auf.

Werkstatt-Übersetzung: Die Autovervollständigung, die zur Uni gegangen ist.

Siehe auch: Token Chatbot Open Weights

ClaudeGeminiLlamaSchublade: Text und Sprache

Lokales Modell

#

Ein Modell, das auf deinem eigenen Rechner oder Server läuft. Die Daten verlassen das Gerät nicht, dafür brauchst du passende Hardware.

Werkstatt-Übersetzung: Die Werkstatt im eigenen Keller: Nichts verlässt das Haus.

Siehe auch: Open Weights Quantisierung GPU

OllamaLM StudioOpen WebUISchublade: Text und Sprache

LoRA

#

Low-Rank Adaptation: sparsame Art des Fine-Tunings, bei der nur kleine Zusatzgewichte trainiert werden. Bei Bildmodellen der übliche Weg zu eigenem Stil oder eigenem Produkt im Bild.

Werkstatt-Übersetzung: Ein Aufsatz für die Bohrmaschine statt einer neuen Bohrmaschine.

Siehe auch: Fine-Tuning Diffusionsmodell

Schublade: Bilder

M

MCP

#

Model Context Protocol: offener Standard, über den KI-Anwendungen an Werkzeuge und Datenquellen angeschlossen werden, etwa Kalender, Datenbanken oder Shop-Systeme. 2024 von Anthropic vorgestellt, inzwischen von vielen Anbietern unterstützt.

Werkstatt-Übersetzung: Die Steckdosennorm für KI: ein Stecker, viele Geräte.

Siehe auch: Agent Tool Use API

ClaudeSchublade: Automatisierung und KI-Agenten

Mixture of Experts

#

Bauweise großer Modelle, bei der pro Anfrage nur ein Teil der Parameter rechnet. Mistral Large 4 hat eine Billion Parameter, davon arbeiten 52 Milliarden gleichzeitig. Das macht große Modelle schneller und billiger im Betrieb.

Werkstatt-Übersetzung: Ein Großraumbüro, in dem bei jeder Frage nur die zuständigen Leute aufstehen.

Siehe auch: LLM Inferenz GPU

Mistral Large 4

Multimodal

#

Ein Modell, das mehr als Text versteht: Bilder, Audio, Video oder PDFs. Praktisch für Screenshots, Rechnungen oder Produktfotos.

Werkstatt-Übersetzung: Kann nicht nur lesen, sondern auch gucken und zuhören.

Siehe auch: LLM OCR

O

OCR

#

Texterkennung in Bildern und Scans. Multimodale Modelle lesen auch Tabellen und Handschrift, machen dabei aber Fehler. Zahlen immer gegenprüfen.

Werkstatt-Übersetzung: Abtippen lassen, ohne dass jemand tippt. Gegenlesen bleibt dein Job.

Siehe auch: Multimodal

Open Weights

#

Die Modellgewichte sind frei herunterladbar, etwa bei Llama oder Mistral. Open Source im strengen Sinn heißt zusätzlich offene Lizenz, offener Code und offengelegte Trainingsdaten. Das erfüllen nur wenige Modelle.

Werkstatt-Übersetzung: Das Rezept liegt offen, die Einkaufsliste der Trainingsdaten meistens nicht.

Siehe auch: Lokales Modell LLM

P

Prompt

#

Deine Anweisung an das Modell. Gute Prompts nennen Rolle, Ziel, Material, Format und Grenzen. Je klarer der Auftrag, desto weniger Nacharbeit.

Werkstatt-Übersetzung: Der Arbeitsauftrag. Unklarer Auftrag, unklares Ergebnis, genau wie bei Menschen.

Siehe auch: System-Prompt Few-Shot Temperatur

Schublade: Lernen: Prompting und KI-Grundlagen

Prompt Injection

#

Angriff, bei dem versteckte Anweisungen in einer Webseite, Mail oder Datei das Modell umsteuern. Gefährlich bei Agenten, die lesen und handeln dürfen.

Werkstatt-Übersetzung: Der Zettel im Paket mit der Aufschrift „Ignoriere alles, was dein Chef gesagt hat“.

Siehe auch: Agent Guardrails

Q

Quantisierung

#

Modellgewichte mit weniger Bits speichern, etwa 4 statt 16. Das Modell wird kleiner und schneller, verliert aber etwas Genauigkeit. So passen große Modelle auf normale Rechner.

Werkstatt-Übersetzung: Das Modell auf Diät: ein bisschen weniger genau, passt dafür auf deinen Laptop.

Siehe auch: Lokales Modell GPU

OllamaLM Studio

R

RAG

#

Retrieval-Augmented Generation: Das Modell sucht vor der Antwort passende Stellen in deinen Dokumenten und antwortet auf dieser Grundlage. Der übliche Weg zum Chat mit Handbuch, Wiki oder Produktdaten.

Werkstatt-Übersetzung: Spickzettel erlaubt. Das Modell schaut erst in deine Unterlagen und antwortet dann.

Siehe auch: Embedding Vektordatenbank Halluzination

NotebookLMLlamaIndexLangChainSchublade: Entwickler-Tools und LLMOps

Rate Limit

#

Obergrenze, wie viele Anfragen oder Token du pro Minute an eine API schicken darfst. Wer Tausende Produkttexte erzeugt, plant Pausen und Wiederholungen ein.

Werkstatt-Übersetzung: Die Drehtür am Eingang: Alle kommen rein, nur nicht gleichzeitig.

Siehe auch: API Token

Reasoning-Modell

#

Modell, das vor der Antwort Zwischenschritte durchrechnet. Besser bei Mathe, Code und Planung, dafür langsamer und teurer pro Anfrage.

Werkstatt-Übersetzung: Erst denken, dann reden. Kostet Zeit, spart Ausreden.

Siehe auch: LLM Token

S

Speech-to-Text

#

Gesprochenes in Text umwandeln, auch Transkription genannt. Grundlage für Meeting-Protokolle, Untertitel und Telefonagenten.

Werkstatt-Übersetzung: Das Protokoll, das sich selbst schreibt, während alle reden.

Siehe auch: Text-to-Speech Multimodal

Whisper APIOtter.aitl;dvSchublade: Audio

System-Prompt

#

Grundanweisung, die vor jedem Chat steht und Rolle, Ton und Regeln festlegt. In eigenen Assistenten der Ort für Markenstimme und Verbote.

Werkstatt-Übersetzung: Die Stellenbeschreibung, die der Assistent vor jedem Gespräch noch mal liest.

Siehe auch: Prompt Guardrails

T

Temperatur

#

Regler für Zufall in der Antwort. Niedrig für Fakten, Daten und Code, höher für Ideen und Varianten.

Werkstatt-Übersetzung: Der Kreativ-Regler: links Buchhaltung, rechts Brainstorming.

Siehe auch: Prompt

Text-to-Speech

#

Text in gesprochene Sprache umwandeln. Heutige Stimmen klingen fast menschlich. Eine fremde Stimme klonst du nur mit Einwilligung der Person.

Werkstatt-Übersetzung: Die Vorlesestimme aus der Steckdose. Fremde Stimmen nur mit Erlaubnis.

Siehe auch: Speech-to-Text Deepfake

ElevenLabsSchublade: Audio

Token

#

Die Einheit, in der Modelle Text zählen. Ein Token ist meist ein Wortteil. Deutsche Texte brauchen in der Regel mehr Token pro Wort als englische, das merkst du an Preis und Kontextfenster.

Werkstatt-Übersetzung: Die Münzen, mit denen du für Text bezahlst. Deutsche Wörter sind lang, also brauchst du mehr davon.

Siehe auch: Kontextfenster API Inferenz

Tool Use

#

Auch Function Calling: Das Modell ruft selbst Funktionen auf, etwa rechnen, im Kalender nachsehen oder in der Datenbank suchen. Die Grundlage für Agenten.

Werkstatt-Übersetzung: Das Modell greift zum Werkzeugkasten, statt alles im Kopf zu rechnen.

Siehe auch: Agent MCP API

Schublade: Automatisierung und KI-Agenten

V

Vektordatenbank

#

Datenbank für Embeddings. Findet Texte nach Bedeutung statt nach exaktem Wortlaut und ist das Gedächtnis vieler RAG-Systeme.

Werkstatt-Übersetzung: Das Archiv, das nach Bedeutung sortiert statt nach Alphabet.

Siehe auch: Embedding RAG

Schublade: Entwickler-Tools und LLMOps

Z

Zero-Shot

#

Prompt ohne Beispiele, nur die Aufgabe. Reicht für Standardaufgaben. Wenn das Format schwankt, wechsel auf Few-Shot.

Werkstatt-Übersetzung: Kaltstart ohne Beispiel. Klappt öfter, als man denkt, und seltener, als man hofft.

Siehe auch: Few-Shot Prompt
