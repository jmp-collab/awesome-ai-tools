      Sammeln

      Gesammelt wird, was in Projekten, Fachartikeln und Herstellerankündigungen auftaucht, mit besonderem Blick auf den DACH-Raum. Jeder Eintrag bekommt einen deutschen Satz, der sagt, wofür das Tool taugt. Ohne Werbeprosa.

      2

      Prüfen

      Jeder Link wird per HTTP abgeklopft. 404, Serverfehler oder Domain weg: ab in die Tonne. Affiliate- und Referral-Parameter bei Tool-Links fliegen auch raus. Nur Links zu PROMPTGOTT tragen UTM-Parameter, damit erkennbar ist, dass der Besuch von hier kam.

      3

      Sortieren

      10 Schubladen nach Aufgabe, nicht nach Hype. EU-Sitz und Open Source als Badge. Dazu Werkzeugkisten für typische Jobs, damit du nicht alle 404 Tools einzeln anfassen musst.

      Was „geprüft“ hier heißt

      • Link-Check: Jeder Link wird automatisch abgefragt, zuletzt am 31.10.2026. Ob ein Tool gut ist, sagt das noch nicht.
      • Beschreibung: Jede ist von Hand auf Deutsch geschrieben und an der Herstellerseite abgeglichen.
      • Kein Praxistest: Nicht jedes Tool wurde ausprobiert. EU-Sitz und Open Source stehen so da, wie die Anbieter sie angeben.
      • Entstehung: Recherche und Entwürfe laufen mit KI-Unterstützung, jede Seite prüft und verantwortet ein Mensch. Mehr im Impressum.
