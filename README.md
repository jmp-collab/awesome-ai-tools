# KI-Werkstatt: AI tools, in German

A German-language, hand-checked directory of 400+ AI tools, sorted by task, with dead links removed and EU-based vendors marked.

- **Website:** https://jmp-collab.github.io/awesome-ai-tools/ (search, stack finder, trends, glossary, use-case pages)
- **The list:** [README.de.md](README.de.md) (German)
- **Data:** [tools.csv](docs/tools.csv) · [tools.json](docs/tools.json) · [feed.xml](docs/feed.xml)

The site is generated from `README.de.md` and `data/*.json` by `scripts/build_de_page.py` (no dependencies). `scripts/check_links.py` checks every link before a build; `scripts/check_unique.py` makes sure no sentence appears twice.

Suggestions are welcome: see [Mitmachen](README.de.md#mitmachen).
